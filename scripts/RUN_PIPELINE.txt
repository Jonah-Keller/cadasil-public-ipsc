E-MTAB-16303 Processing Pipeline
=================================
RNA-seq: iPSC-derived neural crest VSMCs, CADASIL vs control
7 samples, paired-end 76bp, Illumina HiSeq 4000

STEP 0: Download FASTQs (already done / in progress)
-----------------------------------------------------
BAMs from ENA are uBAMs (unaligned). The pipeline will convert BAM->FASTQ
automatically for any sample missing FASTQs.

All data should be in: /sc/arion/scratch/kellej10/cadasil_public_ipsc/

STEP 1: Download reference genome + GTF (login node, needs internet)
--------------------------------------------------------------------
bash /sc/arion/work/kellej10/cadasil_public_ipsc/scripts/00_download_references.sh

STEP 2: Build STAR index (submit to LSF)
-----------------------------------------
bsub < /sc/arion/work/kellej10/cadasil_public_ipsc/scripts/01_build_star_index.lsf

Wait for completion: bjobs -w

STEP 3: Align + count (submit to LSF, after STAR index is done)
---------------------------------------------------------------
bsub < /sc/arion/work/kellej10/cadasil_public_ipsc/scripts/02_align_and_count.lsf

This does:
  - Convert uBAMs -> FASTQs (if needed)
  - STAR alignment -> sorted BAMs
  - featureCounts gene-level counts
  - featureCounts transcript-level counts (for FLT1/FN1/NOTCH3 isoforms)
  - NOTCH3 region pileup (variant evidence)

Wait for completion: bjobs -w

STEP 4: Build final matrices (login node or interactive job)
------------------------------------------------------------
module purge && module load anaconda3/2024.06
conda activate orion-minimal
python /sc/arion/work/kellej10/cadasil_public_ipsc/scripts/03_build_matrices.py

OUTPUTS (in /sc/arion/work/kellej10/cadasil_public_ipsc/):
----------------------------------------------------------
  gene_expression_matrix.csv     - Full gene count matrix (genes x 7 samples)
  sample_metadata.csv            - Paired metadata (genotype, disease, mutation)
  transcript_variant_counts.csv  - FLT1 (mFlt1 vs sFlt1), FN1, NOTCH3 isoforms
  notch3_variant_summary.csv     - NOTCH3 variant pileup evidence per sample
  genes_of_interest_counts.csv   - Subset: FLT1, FN1, NOTCH3, VEGFA, ACTA2, etc.

NOTES:
------
- Scratch has 14-day purge! Final outputs go to work/, intermediate to scratch/
- featureCounts -s 2 assumes reverse-stranded library (TruSeq stranded mRNA)
- STAR --quantMode TranscriptomeSAM also generates transcriptome BAM for Salmon
  if you want more precise transcript quantification later
